A colossal bioluminescent whale breaches out of a night sea, its spray
bursting apart into a flock of golden birds. Below it, a tiny lantern-lit
sailboat gives the scene its scale — one small light against something
impossibly huge. The image is built to excite at a glance: a single
impossible moment, glowing against the dark, with momentum frozen mid-air
and a surprise hiding in the spray. It reads clearly even at small sizes,
because the composition is one big shape — whale, arc of birds, boat —
against a deep blue-black sea.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies `entry.png` from this
directory into the output directory and verifies the copy byte-for-byte by
comparing sha256 hashes. It is deterministic: every run writes the same
bytes.
